# AI Usage Disclosure

## Tools Used

- **ChatGPT (OpenAI)**
- **GitHub Copilot**

## What I Used Them For

### ChatGPT

I used ChatGPT as a development and learning assistant for:

- Understanding assignment requirements and breaking them into implementation steps.
- Understanding data modelling and database schema design.
- Getting guidance on Python implementation and SQL queries.
- Understanding data ingestion, validation, and processing workflows.
- Troubleshooting Python and database-related errors.
- Understanding duplicate handling and idempotency.
- Improving project documentation and README preparation.
- Getting guidance on Git and GitHub submission.

### GitHub Copilot

I used GitHub Copilot primarily for testing assistance:

- Generating suggestions for test cases.
- Assisting with Python test code.
- Identifying potential edge cases.
- Suggesting improvements to test coverage.
- Supporting debugging during test execution.

## What I Wrote or Decided Myself

I was responsible for understanding the assignment, developing the solution, and making implementation decisions.

My contributions included:

- Understanding the input datasets and expected outputs.
- Working on the Python data processing workflow.
- Making decisions about data validation and handling invalid records.
- Working on database connectivity and data loading.
- Reviewing pipeline execution and generated outputs.
- Organizing the project structure and preparing the submission.

I reviewed AI-generated suggestions and adapted them to the actual project requirements.

## Where the AI Was Wrong or Unhelpful

Some AI suggestions did not initially match my project structure or implementation.

For example:

- Some suggested file paths and entry-point names needed adjustment.
- Some Python and SQL suggestions required modifications to work with my database configuration.
- Some suggested test cases needed adjustments to match the actual assignment requirements.

I identified these issues by reviewing the code, checking error messages, and comparing the implementation with the expected behaviour.

## How I Verified AI-Generated Code

I used the following verification approaches:

- Reviewed the suggested Python code.
- Executed the pipeline and inspected its outputs.
- Checked database connectivity and data loading.
- Reviewed data validation and duplicate-handling results.
- Used GitHub Copilot to assist with test creation and testing.
- Reviewed test results and addressed identified issues.
- Compared the implementation against the assignment requirements.

AI tools were used as supporting development tools. I remained responsible for reviewing the code, making implementation decisions, and preparing the final submission.
